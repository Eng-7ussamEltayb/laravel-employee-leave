# نظام إجازات الموظفين
## Employee Leave System

**Portfolio Demo Project** | المستوى: **متوسط** | المؤلف: [Eng-7ussamEltayb](https://github.com/Eng-7ussamEltayb)

### الفكرة
ديمو لسير عمل طلب إجازة: إنشاء، موافقة، رفض — مناسب كوحدة HR داخل ERP.

### التقنيات
PHP / Laravel-style workflow, JSON storage

### المميزات
- إنشاء طلب إجازة
- موافقة/رفض
- حالات pending/approved/rejected

### طريقة التشغيل
1. cd public
2. php -S localhost:8080
3. افتح http://localhost:8080

### هيكل المشروع
```
public/index.php
storage/leaves.json
README.md
```
